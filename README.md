# Realized Volatility, Jump Detection and Duration Modelling

An intraday analysis of a simulated US equity: decomposing quadratic variation into its
continuous and jump components, testing for jumps, comparing realized-range and
realized-volatility estimators, modelling long memory in daily variance, and fitting an
ACD model to transaction durations.

The whole analysis lives in a single, self-contained R Markdown document:
**[`analysis.Rmd`](analysis.Rmd)**.

---

## Overview

The project answers four linked questions about the behaviour of asset prices and
trading activity at high frequency:

| Part | Question | Methods |
| --- | --- | --- |
| **1** | How does a generalised Brownian motion behave, and how well does a simulated sample path match its theoretical distribution? | Exact simulation of $dX_t = dt + 3\,dB_t$; conditional mean/variance; Monte-Carlo study of the terminal distribution |
| **2** | What part of intraday price variation comes from **jumps** rather than continuous diffusion? | Realized variance (RV), bipower variation (BV), the jump contributions $J_1$, $J_2$, $J_3$; tri-power quarticity and one-sided jump tests; realized-range volatility (RRV) |
| **3** | Does daily realized variance display **long memory**, and how should it be modelled? | ARFIMA$(0,d,0)$; the HAR model and its equivalence to a **restricted AR(10)**; autocorrelation comparison |
| **4** | How are **transaction durations** distributed, and how persistent is their conditional mean? | Diurnal adjustment via spline; summary statistics and ACF; ACD(1,1) estimated by **quasi-maximum likelihood** |

---

## Key results

**Part 1 — Generalised Brownian motion.** With $\Delta t=10^{-4}$ the simulated path
tracks the theoretical conditional mean $E(X_t\mid X_3=1)=t-2$ inside 95% pointwise bands
that widen as $\sqrt{t-3}$. Averaging 500 paths gives
$X_5 \sim N(3,\,18)$, and both the simulated mean and variance fall inside their 95%
confidence intervals.

**Part 2 — Jumps.** Each trading day contains 79 five-minute prices and 78 within-day
returns (overnight returns excluded).

- The signed jump measure $J_1=\mathrm{RV}-\mathrm{BV}$ has a mean indistinguishable from
  zero, but extreme right skewness (9.09) and kurtosis (156) — a few very large positive
  contributions dominate.
- $J_1$ shows a **negative lag-1 autocorrelation** ($-0.277$). This is a *mechanical*
  artifact of BV being built from adjacent returns, not evidence of jump clustering.
- The ratio measure $J_3=J_1/\mathrm{RV}$ is **not usable**: when RV is small the ratio
  explodes (minimum $-377$, skewness $-13.3$).
- One-sided $J_1$ jump tests **reject the null of no jump variation** for the first
  30-minute interval on 27 April ($z=3.45$), for the whole sample ($z=3.89$) and, most
  strongly, for the final trading week ($z=6.64$).

**Part 3 — Long memory.** $\hat d = 0.483$, indicating strong but stationary long memory
($0<d<0.5$). The HAR model explains $R^2 = 0.543$ of daily realized variance, and the
$F$ test **cannot reject** the restrictions it imposes on an unrestricted AR(10)
($F(7,1022)=0.64$, $p=0.72$) — so the parsimonious HAR specification is adequate.

**Part 4 — Durations.** Raw durations are strongly right-skewed (skewness 3.51,
kurtosis 25.96); removing the intraday pattern reduces but does not eliminate this. The
fitted ACD(1,1) has
$\hat\alpha = 0.042$ and $\hat\beta = 0.949$, so persistence is
$\hat\alpha+\hat\beta = 0.991$ — very close to one, indicating that duration shocks decay
only slowly.

## How to run

1. Open `analysis.Rmd` in RStudio (or any editor with R Markdown support).
2. Install the required packages if you have not already:

   ```r
   install.packages(c("readxl", "dplyr", "tidyr", "ggplot2", "moments",
                      "lubridate", "fracdiff", "rugarch", "gridExtra"))
   ```

3. Click **Knit**. The document is self-contained: it reads the data from `data/`,
   runs the full analysis, and produces tables and figures inline.

> **Note.** Set `echo = FALSE` in the setup chunk if you want an output-only report
> without the code.

## Method notes

A few implementation choices are worth flagging, since they are easy to get wrong.

**Simulating the SDE exactly.** For a generalised Wiener process with constant
coefficients the increments are exactly $N(\mu\Delta t,\sigma^2\Delta t)$, so the path is
simulated by drawing increments directly rather than discretising the SDE.

**Tri-power quarticity scaling.** The jump statistic is standardised by
$\sqrt{\theta\sum \mathrm{TP}}$ with $\theta=\pi^2/4+\pi-5\approx0.609$. The textbook
formula for TP contains a $\Delta t^{-1}$ factor; here it is kept *outside* the
accumulated sum, which is equivalent and avoids having to pin down $\Delta t$ in
year-units.

**Tables rendered as images.** Console output from `print()` is split by `knitr` into
many small blocks and is hard to read. The helper `tab_fig()` draws each table as a
graphic with `gridExtra::tableGrob()`, transposing wide tables so that each statistic
becomes a row.

**GARCH software to fit an ACD model.** The ACD(1,1) model
$x_i=\psi_i\varepsilon_i$ is estimated by mapping it onto a zero-mean GARCH(1,1) applied
to $\sqrt{x_i}$, using normal errors as an approximation to the exponential innovation.
This makes the estimator *quasi*-maximum likelihood — consistent but inefficient — so
Bollerslev–Wooldridge robust standard errors are reported.

**Diurnal adjustment.** Transaction durations follow a systematic intraday pattern
(frequent at the open and close, sparse around midday). Dividing by an estimated spline
removes this deterministic component so that the residual dynamics can be modelled.
